# Archived standard-library prototypes

These files are historical/future-source experiments and **are not part of the qualified v0.1.2 runtime or standard library**. They were moved out of active source locations during the 0.0.1–0.1.2 lineage remediation because several contain placeholder return values, recursive stand-ins, duplicate snapshots, or syntax from older parser experiments.

The active bootstrap helper library is `crates/omni-stdlib/src/lib.rs`. The remaining `omni/stdlib/` tree is future Omni-source library work and is also not linked by the v0.1.2 compiler.
