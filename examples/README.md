# Qualified examples

These examples are intentionally limited to the v0.1.2 canonical native subset.

- `native_hello.omni` — literal output and integer return.
- `native_edition1.omni` — scalar function call, checked integer arithmetic, output and return.
- `native_loop_control.omni` — `while`, `if`, `continue`, `break`, mutation and return.

Older parser, ownership, generic, stdlib and match experiments were moved to
`docs/archive/legacy-scratch/examples/` because they are not evidence of native feature
support at this milestone.
